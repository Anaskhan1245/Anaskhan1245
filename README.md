## Featured Projects

### 01 · Azure Financial Transaction Risk & Fraud Analytics

**Python · ADLS Gen2 · Azure Data Factory · Azure SQL · Power BI · DAX**

[![Financial transaction risk overview](https://raw.githubusercontent.com/Anaskhan1245/azure-financial-fraud-analytics/main/images/1-Overview%20and%20Risk.png)](https://github.com/Anaskhan1245/azure-financial-fraud-analytics)

**Business Question**  
Where is fraud concentrated, and which transaction patterns warrant further investigation?

**What I Built**

- Prepared a **21-column analytical dataset** in Python, including balance checks, amount percentiles, and rule-based risk indicators.
- Manually uploaded the cleaned data to **ADLS Gen2** and configured an **Azure Data Factory batch copy to Azure SQL**, with column mappings and managed-identity authentication.
- Validated **6,362,620 transactions** and **8,213 fraud-labelled records** using SQL checks.
- Developed a **two-page Power BI report** covering transaction patterns, fraud rates, high-value transactions, account-level exposure, and recommendations.

**Key Finding**  
The overall fraud rate is approximately **0.13%**. TRANSFER and CASH_OUT account for the fraud amount. The Low-risk category shows a higher observed fraud rate than the High-risk category, highlighting a need to review the scoring rules.

**Recommended Action**  
Prioritise relevant transaction groups for investigation and validate risk thresholds before operational use.
